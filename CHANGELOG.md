# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-08-20

### Added

- Initial release of `ompshot`.
- Native `iris` tool integration for Pi and Oh My Pi coding agents.
- Support for inline base64 image emission, element selection, viewport presets, and dark mode emulation.
- Dual schema support for OMP (Zod) and Pi (TypeBox).
